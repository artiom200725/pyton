## 1. Цель работы
Изучение синтаксиса и практических возможностей условных операторов (`if-elif-else`), циклических конструкций (`while`, `for..in`) и пользовательских функций (`def`) в языке Python. Приобретение навыков декомпозиции алгоритмов управления, передачи аргументов и возврата результатов вычислений.

## 2. Постановка задачи
Разработать функцию `vibration_diagnostic(vibe_data)`, классифицирующую замеры виброскорости:
*   $V < 2.8$ мм/с — «Замечательно»
*   $2.8 \le V < 7.1$ мм/с — «Допустимо»
*   $V \ge 7.1$ мм/с — «Авария»

Функция должна возвращать процент аварийных замеров.

## 3. Краткие теоретические сведения
*   **Условный оператор `if-elif-else`:** Используется для проверки логических условий и ветвления алгоритма. Конструкция `elif` позволяет связывать несколько последовательных проверок без лишней вложенности. Блок `else` выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия (`:`) и соблюдение отступов (4 пробела).
*   **Цикл `for..in`:** Осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция `range(start, stop, step)` генерирует арифметическую прогрессию чисел, не включая верхнюю границу `stop`.
*   **Пользовательские функции (`def`):** Многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова `def`, принимает параметры и возвращает результаты вычислений оператором `return`. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции.

## 4. Исходный код программы
```python
def vibration_diagnostic(vibe_data):
    """Классифицирует замеры виброскорости и возвращает процент аварийных замеров."""
    if not vibe_data:
        return 0.0
    alarm_count = 0
    for v in vibe_data:
        if v >= 7.1:
            alarm_count += 1
    return (alarm_count / len(vibe_data)) * 100

vibe_data = [1.5, 2.7, 3.0, 5.5, 7.2, 8.0, 2.0]
print(f"Процент аварийных замеров: {vibration_diagnostic(vibe_data):.2f}%")
```

## 5. Ответы на контрольные вопросы
1.  **Какова синтаксическая роль отступов и двоеточия при объявлении функций и условных блоков в Python?**  
    Двоеточие (`:`) отделяет заголовок конструкции (функции, условия, цикла) от тела. Отступы (4 пробела) определяют принадлежность строк к блоку — все строки с одинаковым отступом образуют единый блок кода. Без отступов Python не сможет определить границы блоков и выдаст ошибку `IndentationError`.
2.  **В чем различие между параметрами функции при объявлении и аргументами при вызове?**  
    Параметры — это переменные, указанные в заголовке функции после `def` (например, `vibe_data`). Аргументы — это конкретные значения, которые передаются функции при её вызове (например, список `[1.5, 2.7, 3.0]`). Параметр — «ячейка», аргумент — «значение в ячейке».
3.  **Как оператор `return` передает результаты работы функции?**  
    `return` завершает выполнение функции и отправляет вычисленное значение обратно в точку вызова. Результат можно сохранить в переменную, вывести через `print` или использовать в дальнейших вычислениях. Если `return` не указан, функция возвращает `None`.
4.  **Как работают `if-elif-else` и операторы `break` и `continue` внутри циклов?**  
    `if-elif-else` проверяет условия по порядку: если условие `if` истинно — выполняется его блок; иначе проверяется `elif`; если ни одно не подошло — выполняется `else`. `break` немедленно прерывает цикл. `continue` пропускает оставшиеся строки текущей итерации и переходит к следующей.
5.  **Какими способами можно организовать форматированный вывод в Python?**  
    *   f-строки: `f"Значение: {x:.2f}"`
    *   Метод `str.format()`: `"Значение: {:.2f}".format(x)`
    *   Оператор `%`: `"Значение: %.2f" % x`
    *   Преобразование типов: `str(x)`
