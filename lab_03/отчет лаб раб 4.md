## 1. Первоначальная настройка и конфигурация Git
Перед началом работы была проверена версия установленного ПО и заданы глобальные параметры пользователя, которые будут отображаться в истории коммитов.

```bash
$ git --version
git version 2.56.0.windows.2

$ git config --global user.name "Герман Артём"
$ git config --global user.email "artiom200725@gmail.com"
```

## 2. Создание структуры проекта и инициализация
На локальном диске была создана рабочая директория проекта `pyton` и запущена инициализация локального репозитория. По умолчанию была создана ветка `master`. Далее внутри проекта сформирована папка для первой лабораторной работы.

```bash
$ mkdir pyton
$ cd pyton

$ git init
Initialized empty Git repository in C:/Users/user/pyton/.git/

$ mkdir lab_01
```

## 3. Фиксация изменений (Коммит)
При проверке статуса репозитория Git обнаружил новую неотслеживаемую папку `lab_01` (содержащую файл с решением). Все файлы были добавлены в индекс отслеживания и зафиксированы с помощью коммита.

```bash
$ git status
On branch master
Untracked files:
  (use "git add <file>..." to include in what will be committed)
        lab_01/

$ git add .

$ git commit -m "Initial commit: create structure and lab_01"
[master (root-commit) dd73fab] Initial commit: create structure and lab_01
 1 file changed, 12 insertions(+)
 create mode 100644 "lab_01/лаб раб 1.py"
```

## 4. Переименование ветки и связывание с GitHub
Главная локальная ветка была переименована из `master` в `main` в соответствии с современными стандартами GitHub. После этого локальный репозиторий был успешно связан с удаленным сервером под именем `origin`.

```bash
$ git branch -M main

$ git remote add origin https://github.com/artiom200725/pyton.git
```

## 5. Публикация кода на GitHub
Команда `push` отправила локальные файлы в удаленный репозиторий. Для завершения операции потребовалось пройти авторизацию в браузере. Ветка `main` на GitHub теперь отслеживает изменения из локальной ветки.
