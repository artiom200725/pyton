## Краткие теоретические сведения

*   **Модуль в Python** — это отдельный файл с расширением `.py`, содержащий определения функций, переменных и классов, обеспечивающий декомпозицию и повторное использование кода.
*   **Импорт модулей** — подключение стороннего или встроенного функционала. Осуществляется в общей форме `import module` или точечно из пространства имен через `from module import function`.
*   **Точка входа `__name__`** — проверка значения системной переменной `if __name__ == '__main__':` для отделения основного исполняемого кода или тестов модуля от его функций при импортировании.
*   **Системный модуль `sys` и `sys.argv`** — модуль для взаимодействия со средой исполнения. Список строк `sys.argv` хранит аргументы командной строки, переданные скрипту при его вызове из терминала.
*   **Базовые структуры данных:**
    *   *Списки (list)* — упорядоченные изменяемые динамические массивы (`[]`).
    *   *Кортежи (tuple)* — упорядоченные неизменяемые последовательности для защиты данных (`()`).
    *   *Словари (dict)* — изменяемые ассоциативные массивы пар «ключ: значение» (`{}`).
    *   *Множества (set)* — неупорядоченные коллекции уникальных элементов для математических операций (`{}`).
*   **Срезы** — извлечение фрагмента последовательности по синтаксису `[start:stop:step]`. Отрицательный шаг `-1` выполняет быстрый разворот элементов в обратном порядке.

## Исходный код программы (Листинги)

Программа разделена на два файла согласно Варианту 6 (Диспетчеризация резервуарного парка НПЗ).

### 1. Файл пользовательского модуля `func1.py`
```python
def get_critical_tanks(tanks_dict, threshold=90.0):
    """Принимает словарь резервуаров, возвращает емкости выше порога threshold."""
    result = {}
    for name, percent in tanks_dict.items():
        if percent > threshold:
            result[name] = percent
    return result


def sort_tanks_by_volume(tanks_dict):
    """Возвращает отсортированный по убыванию объемов список кортежей (id, vol)."""
    return sorted(tanks_dict.items(), key=lambda x: x, reverse=True)


def slice_history(tank_history, step=2):
    """Выполняет прореживание временного ряда налива резервуаров с шагом step."""
    return tank_history[::step]


# Блок автономного тестирования модуля
if __name__ == '__main__':
    print("--- [ТЕСТ] Автономный запуск модуля func1.py ---")
    test_tanks = {'RVS-1': 82.5, 'RVS-2': 93.1, 'RVS-3': 65.0, 'RVS-4': 91.8}
    test_history = [10, 20, 35, 50, 68, 82, 93]
    
    print(f"Тест критических (>90%): {get_critical_tanks(test_tanks)}")
    print(f"Тест сортировки объемов: {sort_tanks_by_volume(test_tanks)}")
    print(f"Тест среза истории (шаг 2): {slice_history(test_history, 2)}")
    print("--- [ТЕСТ] Автономная проверка завершена ---\n")
```

### 2. Главный исполняемый файл `main.py`
```python
import sys
from func1 import get_critical_tanks, sort_tanks_by_volume, slice_history

# Динамическое чтение шага прореживания из аргументов командной строки sys.argv
# Если аргумент не передан, используется значение по умолчанию (2)
step = int(sys.argv[1]) if len(sys.argv) > 1 else 2

# Исходные структуры данных
tanks = {'RVS-1': 82.5, 'RVS-2': 93.1, 'RVS-3': 65.0, 'RVS-4': 91.8}
history = [10, 20, 35, 50, 68, 82, 93]

# Вызов функций импортированного модуля
critical = get_critical_tanks(tanks)
sorted_tanks = sort_tanks_by_volume(tanks)
thinned = slice_history(history, step)

# Формирование консольного сводного отчета диспетчера
print("=== ДИСПЕТЧЕР РЕЗЕРВУАРНОГО ПАРКА ===")
print(f"Заданный шаг прореживания (sys.argv): {step}")
print(f"Все резервуары в парке: {tanks}")
print(f"Критический уровень (>90%): {critical}")
print(f"Резервуары по убыванию заполнения: {sorted_tanks}")
print(f"Прореженная история налива (срез [::{step}]): {thinned}")

# Дополнительная проверка изменения уставки лимита контроля
print(f"Контрольная проверка для лимита 80%: {get_critical_tanks(tanks, 80.0)}")
```

## Ответы на контрольные вопросы для защиты отчета

### 1. В чем заключается принципиальная разница между инструкцией import module и формой from module import function? Опишите особенности работы с пространствами имен.
Инструкция `import module` подключает весь модуль целиком, при этом создается изолированное пространство имен модуля. Для вызова функций необходимо использовать префикс: `module.function()`, что исключает конфликты имен. Форма `from module import function` копирует конкретную функцию напрямую в текущее пространство имен программы. Префикс становится не нужен, но возникает риск перезаписи одноименных локальных функций.

### 2. Какую роль играет переменная __name__ и конструкция if __name__ == '__main__': при разработке пользовательских модулей?
Переменная `__name__` определяет контекст запуска программного файла. Если файл запущен пользователем напрямую, интерпретатор присваивает ей значение `'__main__'`. Если файл импортируется другой программой, туда записывается имя самого модуля (например, `'func1'`). Конструкция `if __name__ == '__main__':` позволяет изолировать локальный отладочный код и автотесты от основной логики, предотвращая их случайный запуск при импорте.

### 3. Какую роль выполняет системный модуль sys и список аргументов sys.argv при запуске программ из командной строки?
Модуль `sys` организует взаимодействие скрипта с интерпретатором и операционной системой. Список `sys.argv` собирает текстовые параметры, указанные через пробел при запуске программы из консоли. `sys.argv` хранит путь к скрипту, а индексы `[1:]` — внешние входные настройки (например, коэффициенты или шаги фильтрации), избавляя от ручного изменения исходного кода перед каждым запуском.

### 4. Сформулируйте основные различия между списками (list), кортежами (tuple), словарями (dict) and множествами (set).
*   **Списки (`list`)** — упорядоченные, индексируемые и изменяемые коллекции элементов (динамические массивы).
*   **Кортежи (`tuple`)** — упорядоченные, индексируемые, но строго неизменяемые структуры для защиты целостности данных.
*   **Словари (`dict`)** — изменяемые коллекции пар «ключ: значение» с быстрым ассоциативным поиском по уникальному ключу.
*   **Множества (`set`)** — неупорядоченные изменяемые наборы, содержащие исключительно уникальные элементы; используются для математических операций исключения повторов.

### 5. Опишите синтаксис срезов последовательностей [start:stop:step]. Какое значение принимает срез при использовании отрицательного шага -1?
Синтаксис среза извлекает часть последовательности: `start` задает начальный индекс включительно, `stop` — конечную границу не включая ее, а `step` определяет шаг (периодичность) движения по индексам. Если шаг равен `-1`, обход элементов начинает выполняться в обратном направлении — от конца к началу, что приводит к быстрому развороту (инверсии) последовательности (например, `sequence[::-1]`).
