## 2. Постановка задачи
Написать скрипт, вычисляющий силу Лоренца для движущегося заряда по формуле:
$$F = q \times v \times B$$

**Исходные параметры:**
*   $q = 1,6 \times 10^{-19}$ Кл — заряд частицы
*   $v = 3 \times 10^5$ м/с — скорость движения
*   $B = 0,5$ Тл — магнитная индукция

Значения вводятся пользователем с клавиатуры. Программа должна обрабатывать некорректный ввод с помощью конструкции `try/except`.

## 3. Краткие теоретические сведения
Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной (CPython). Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (4 пробела) обязательны и служат для группировки блоков кода.

Функция `input()` считывает строку из стандартного ввода и возвращает её как строку (`str`). Для преобразования строки в число используется функция `float()`.

Конструкция `try/except` обеспечивает обработку исключений: код в блоке `try` выполняется первым, и если возникает ошибка (например, `ValueError` при преобразовании нечислового текста в `float`), выполнение переходит в блок `except`.

## 4. Исходный код программы
```python
q = input('введите q: ')
v = input('введите v: ')
B = input('введите B: ')
try:
    F = float(q) * float(v) * float(B)
    print(f"Сила Лоренца F = {F}")
except ValueError:
    print("ВВЕДЕНЫ НЕКОРРЕКТНЫЕ ДАННЫЕ")
```

## 5. Результаты выполнения программы
*   **Тест 1 — корректный ввод** ($q = 1.6e-19, v = 3e5, B = 0.5$):
    ```text
    введите q: 1.6e-19
    введите v: 3e5
    введите B: 0.5
    2.4e-14
    ```
    *Расчет:* $F = 1,6 \times 10^{-19} \times 3 \times 10^5 \times 0,5 = 2,4 \times 10^{-14}$ Н.

*   **Тест 2 — некорректный ввод** ($q = abc, v = 3e5, B = 0.5$):
    ```text
    введите q: abc
    введите v: 3e5
    введите B: 0.5
    ВВЕДЕНЫ НЕКОРРЕКТНЫЕ ДАННЫЕ
    ```
    При вводе нечислового значения `abc` функция `float()` вызывает исключение `ValueError`, и программа переходит в блок `except`, выводя сообщение об ошибке.
